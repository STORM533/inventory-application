# Inventory Management System

A simple inventory management web application built with **Express.js** and **PostgreSQL**.

## Features

- Manage inventory categories
- Add items to categories
- View categories and items
- Edit items
- Delete items
- Admin password protection for edit/delete actions
- PostgreSQL database

## Tech Stack

- Node.js
- Express.js
- PostgreSQL
- EJS
- CSS

## Database

The application will use a relational database.

```text
Category 1 ──────── * Items
```

Each category can contain multiple items, while each item belongs to one category.
